# Today Planner — Android setup

This is a mobile-first Progressive Web App (PWA).

## Important
A PWA normally needs to be opened from a website (HTTPS) before Chrome can install it as a home-screen app. Opening index.html directly from a file may not show the Install option.

## Easy free setup with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository, for example `today-planner`.
3. Upload `index.html`, `manifest.json`, and `sw.js`.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch", select the main branch and root folder, then save.
6. Open the generated GitHub Pages URL in Chrome on Android.
7. Chrome menu → Add to Home screen / Install app.

The planner stores your tasks and notes in the browser on that device.
